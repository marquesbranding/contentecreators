# Accessibility audit — MVP

Date: 2026-07-29  
Target: WCAG 2.2 level AA  
Scope: public, authentication, onboarding, status, private catalog, profile and backoffice critical journeys.

## Method and acceptance criteria

- Keyboard-only traversal checks the first actionable control, logical tab order, visible focus, Enter/Space activation, Escape dismissal, modal focus containment and return to the invoking control.
- Navigation checks one global “Pular para o conteúdo” link and one focusable `main#main-content` landmark per rendered route.
- Form checks cover persistent labels, required-field semantics, adjacent descriptions/errors, invalid-summary links and focus on the first invalid control.
- Async checks cover visible `pt-BR` status plus `aria-live`; active CNPJ lookup additionally exposes `aria-busy`.
- Axe runs the WCAG 2 A/AA, WCAG 2.1 A/AA and WCAG 2.2 AA rule tags on representative anonymous routes. Component scans cover complex authenticated controls without weakening the serious/critical release gate.
- Reflow checks run at 320 CSS px (equivalent to 400% zoom on a 1280 px viewport) and with WCAG text-spacing overrides. Existing responsive suites also cover 390, 768 and 1440 px.
- Reduced-motion checks require automatic scrolling and animation/transition durations of at most `0.01ms`.
- Images must have meaningful alternative text when they convey profile, company or sponsorship content. Decorative previews, gradients and icons remain hidden from assistive technology.

## Findings resolved

1. Public marketing had the only skip link. A single shared skip link now precedes every application surface, and every rendered main landmark has the same focusable target.
2. Protected backoffice routes inherited one generic document title. Each critical backoffice route now supplies a concise, unique `pt-BR` title so Next.js route announcements identify the destination.
3. The CNPJ loading alert announced its text but did not expose that the region was busy. It now sets `aria-busy="true"` until the result replaces it.
4. Modal focus behavior was delegated correctly to Base UI but lacked explicit regression evidence. The onboarding confirmation test now proves focus containment, Escape dismissal and trigger focus restoration.
5. Existing Axe smoke tests only failed serious/critical issues. The anonymous critical-route matrix now runs all automated WCAG A/AA-tagged rules and separately retains the blocking-impact helper for broad smoke suites.

## Residual manual checks before production approval

Automated checks cannot prove every success criterion. Before release, perform one manual pass with VoiceOver + Safari and one with keyboard-only Chromium over seeded approved-company and administrator accounts. Confirm spoken route names, reading order of real catalog media, browser-native 200% text zoom, high-contrast/forced-colors presentation and comprehensibility of client-approved legal copy. Record only defects; this checklist does not block implementation progress when no production-like content is available.
