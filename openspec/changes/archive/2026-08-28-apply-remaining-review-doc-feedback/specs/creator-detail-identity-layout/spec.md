## ADDED Requirements

### Requirement: Creator-type badge renders below the display name
The public creator detail page SHALL render the creator-type badge (Creator UGC / Influenciador) directly below the creator's display name, not above it.

#### Scenario: User views a creator's detail page
- **WHEN** the creator detail page renders
- **THEN** the `<h1>` display name appears first, followed immediately by the creator-type badge
